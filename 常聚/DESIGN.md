# DESIGN.md — 常聚 · Gatherly（炉边·温润质感）

> 全站唯一视觉规范。任何页面/组件改动必须遵守本文档；改动本文档须经用户确认。

## 气质

围炉煮茶的温润触感：奶油纸底带噪点、暖杏渐变、大圆角软阴影、拍立得与票券的"物感"。**温情不烫、热闹不吵。**

## 色彩令牌（theme.css :root）

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--cream` | `#FBF4E8` | 页面底色（奶油） |
| `--cream-deep` | `#F6E8D4` | 渐变尾（暖杏） |
| `--card` | `#FFFFFF` | 卡片 |
| `--ink` | `#3B2E22` | 标题/主文字（墨棕） |
| `--body` | `#6B5A48` | 正文 |
| `--caption` | `#A58C70` | 题注/小字 |
| `--line` | `#EFE2CD` | 描边/分隔 |
| `--warm` | `#E08A3C` | 主色（焦糖橙）：按钮/激活态/关键数字 |
| `--warm-deep` | `#C97226` | 主色深（渐变尾/强调文字） |
| `--warm-soft` | `#F9EBD8` | 主色浅底（胶囊/选中底） |
| `--seal` | `#C4502A` | 印章红（仅"已结清/当值"等盖章元素） |

背景 = `linear-gradient(180deg, cream 0%, cream-deep 130%)` + SVG 噪点叠层（opacity 0.35 multiply）。**页面内禁止再出现其他渐变，除主按钮与当值卡。**

## 字体

- 正文/标题：`PingFang SC / Microsoft YaHei / sans-serif`
- 字号阶梯：页面大标题 22/800、区块标题 15/800、正文 14、题注 11-12/600
- 不使用宋体/衬线（方案 B 为圆润无衬线）；不使用字距拉开的"小字号大字距"排版

## 组件语言

- **卡片**：白卡 `border-radius:20px` + 暖调软阴影 `0 10px 28px -12px rgba(107,76,41,.28)` + 细描边 `rgba(239,226,205,.7)`；页边距统一 20px
- **胶囊徽章**：`border-radius:999px`，状态三色——进行中/提醒用 `--warm-soft` 底 + `--warm-deep` 字；普通信息 `#F6F1E8` 底 + `--caption` 字
- **主按钮**：胶囊形 `999px`，`135deg` 主色渐变 + 主色投影 `0 12px 24px -10px rgba(201,114,38,.55)`；描边按钮 = 白底 + 主色 1.5px 边
- **拍立得**（时间轴/合影）：白卡 + 内图 4:3 圆角 6px + 顶部胶带（56×14 半透明橙）+ 微旋转（±2° 交替）+ 题注（日期小字/标题 14/800）
- **票券**（AA 账本条目）：白卡 16px 圆角 + 撕票虚线 `1.5px dashed #E5D5B8` + 两侧缺口圆 + 金额大字 `--warm-deep` + 印章（`--seal` 2px 边框旋转 -6°）
- **便签**（留言）：`#FDF3D8` 底 + 12px 圆角（左下角 2px）+ 软投影
- **当值张罗卡**：`135deg #FBE7CD→#F6D9B6` 渐变 + 头像白描边 3px + 右侧大数字（20px 主色深）+ 渐变进度条（高 6px 胶囊）
- **tabbar**：悬浮药丸（白底 999px 圆角 + 软阴影 + lucide 图标 18px + 标签 10px），激活项 `--warm-soft` 底 + `--warm-deep` 字
- **顶栏**：左侧品牌词（22/800 墨棕，接主色"·"）+ 右侧 slogan 胶囊；页面标题用同款但 19px

## 图片

- 聚会合影一律 4:3 裁切（`aspect-ratio:4/3; object-fit:cover`），大图圆角 20px 有投影；列表缩略 58×58 圆角 14px
- 头像 = 圆形 + 2px 白描边 + 暖投影

## 动效（全站仅保留这两处）

1. 散场抽签：头像轮转（0.8s 渐停，木签筒氛围）
2. 入圈/表态等状态变化：淡入 0.3s

## 文案规则

温情不催债：提醒是"想念"，账本是"帮忙"；禁用"催"字。
