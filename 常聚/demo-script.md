# 常聚 · Gatherly 演示剧本（demo-script.md）

演示入口：**双击 `index.html`**（全新用户默认落在组局引导）；`wechat.html` 提供"群内两条消息"的微信侧演示入口。右下角「演示」悬浮钮可模拟圈友表态/推进时间/重置（重置会清空授权态与数据）。

## 路线①：全新用户（约 4 分钟）

**场景话术**："一个从没注册过的新用户，打开常聚做的第一件事是组局，而不是建圈子。"

1. 双击 `index.html`（全新浏览器）→ **默认落在「组局」页签**，高格调引导：「**多久没聚了？**」+ 小拍立得 + "有些圈子，散着散着就远了。组一局，把人聚回来。" → 点「**马上开始组局**」；
2. `auth.html`：**手机号授权弹层**（申请获取你的手机号 · 138 **** 8000）→ 「允许」；
3. `register.html`：**注册**（选头像、昵称、手机号回显不可改、性别）→ 「完成注册」；
4. `profile.html`：**资料完善**（出生日期/爱好/MBTI/空闲时间/工作地点/住处——两个地点均为商圈级定位，不填具体地址），可**跳过**以后在个人中心补；话术："这些信息只用于智能组局推荐，不向圈友展示。"
5. 进入 `propose.html?new=1`：**四步清晰推进**——①新建圈子（选类型自动预填圈名 → 「创建圈子，继续组局」）②选活动项目（类别胶囊 → 项目卡，可多选最多 3 个）③时间+地点（默认 3 个时间候选可编辑/增删 + 按主项目类别过滤的商户卡最多 3 个候选）④**生成邀请卡片**（圈名/全部项目/时间/地点预览）；
6. 「发出提案，请圈友表态」→ 自动弹**分享到群**浮层 → 选群 → 话术："邀请已经躺进微信群，接下来是被邀请人的路线。"
7. `vote.html`：时间矩阵表态 + 随大流 → 「演示」模拟圈友表态 → `event.html`：发起人可**手动结束投票**（或等截止自动定案）→ 进入**进行中**：名单分已参加/待确认（待确认圈友可确认、演示面板可模拟确认）→ 「结束组局」弹窗（提醒合影/算账/下次张罗人）→ 散场仪式；

## 路线②：被邀请用户（约 4 分钟）

**场景话术**："群里的朋友看到组局邀请卡，点进来的完整旅程。"

1. `wechat.html` → 群聊第二条消息（阿Sun：这周的局我组好了）→ 点**组局邀请卡片**；
2. `auth.html`：手机号授权 → 「允许」；`register.html`：注册（头像/昵称/手机号/性别）；`profile.html`：资料完善（可跳过）；
3. 自动直达 `vote.html?proposal=p1`（**无需找圈、找局**）→ 时间矩阵表态、地点投票；
4. 用「演示」推进时间 → `event.html` 局详情（定案/出席名单/未表态提醒）；
5. 收尾点题："被邀请人从卡片进来，授权注册后直接落在局上——这就是'缺人补位'入口的雏形。"

## 汇合后的主线（两个路线共用，约 3 分钟，可选）

散场仪式（合影→抽签→记录卡）→ AA 账本（票券/随机买单转盘/最少转账）→ 现场小游戏（曲水流觞/大转盘）→ 年度回顾。

## 次线一句话带过

- `message.html`：三类提醒分组；`me.html`：节律设置/顺延/演示控制；
- `merchant.html?id=v1`：合作商户与订座权益（商业化种子）。

## 重置

演示结束点「演示」→"重置演示数据"（清空时钟/数据/授权态/注册资料），可重复演示。
