# 常聚 · Gatherly 演示剧本（demo-script.md）

演示入口：**双击 `wechat.html`**。全流程约 8-10 分钟。右下角有「演示」悬浮钮（模拟圈友表态 / 推进时间 / 重置）。

## 第一幕：从微信群到圈子（1 分钟）

1. 打开 `wechat.html`——模拟微信里"周五麻将局"群聊，聊天记录里躺着一条常聚小程序卡片。
   - 话术："熟人组局都发生在微信群里，但群里没有机制、没有记忆。点一下这张卡片，群就变成了有状态的圈子。"
2. 点击卡片 → 进入 `index.html` 圈子列表。
   - 话术："这是圈子列表。注意每个圈子的状态：'周五麻将局'提案进行中，'周末球局'已 58 天没聚、该张罗啦——这就是'让圈子不散'的第一件武器。"

## 第二幕：轮值张罗 + 记忆时间轴（2 分钟）

3. 进入 `circle.html?id=c3`（周末球局）：
   - **当值张罗卡**："该张罗啦"提醒，附上次聚会的合影——提醒是思念，不是骚扰；
   - **记忆时间轴**：每次聚会一张卡，圈子的共同历史；
   - 点"**想念大家了**"→ 模拟微信服务通知浮层弹出。
4. 进入 `circle.html?id=c1`（周五麻将局）：时间轴两场聚会，点"张罗个局"。

## 第三幕：组局流程（2 分钟）

5. `propose.html?circle=c1` → 点"**一键生成智能提案**"：
   - 话术："系统基于圈友的位置、工作节奏、兴趣和消费偏好，推荐项目、地点、3 个时间候选。张罗门槛降到一次点击。"
   - 可选演示："改为待定"（项目交给圈友投票）、"+ 加时间"。
6. 发出提案 → `vote.html`：
   - **时间矩阵表态**："我可/我不行"，最齐时间横幅实时算出；
   - 点"**随大流**"提交自己的表态。
7. 点右下角「演示」→ "模拟圈友表态"，再点"推进时间 +24 小时"×2 → 进 `event.html?proposal=p1`：**自动定案**，出席名单、地点、时间全定；未表态者可"提醒一下"。

## 第四幕：散场仪式（高光，1.5 分钟）

8. `event.html` 点"散场 · 记录这次聚会" → `end-event.html` 三步：
   - **① 上传合影**（点选 2-3 张）；
   - **② 抽签交接**——头像轮转，抽出"下一任张罗"；
   - 话术："组织不靠一个人的热情。散场那一刻，下一场已经有人在张罗了。"
   - **③ 留一句话** → 生成记录卡 → `record.html`（合影/出席/买单方式/留言）。

## 第五幕：AA 账本（1.5 分钟）

9. `record.html` 点"去 AA 账本" → `ledger.html?gathering=g2`（老同学的账本）：
   - 账单条目 + "记一笔"；
   - **随机买单转盘**（点击后 SVG 转盘定停）+ 请客 / 均摊三选一；
   - **结算清单**：债务合并后的最少转账笔数；
   - 全部点"已转账"→ 状态变"已结清"；未结清文案轻松不催债。

## 第六幕：现场小游戏（高光，1 分钟）

10. `game-liushang.html`（从 event.html"聚会中 · 玩一局"进入）：
    - 水墨山水 + 水面流动 + 酒杯漂流，停杯弹**觞令卡**（真心话/大冒险/表演/吟诗）；
    - 话术："这是王羲之的曲水流觞，中国最早的聚会现场游戏。"
    - 同页链接 `game-wheel.html` 大转盘："谁点菜 / 真心话 / 免死金牌"。

## 第七幕：年度回顾（高光，1 分钟）

11. `memory.html?circle=c1`：
    - 封面 SLOGAN「常聚常伴，圈子不散」→ 数据页：聚了 N 次、M 个地方、首场末场、垫付之王、随机买单幸运儿 → 合影墙 → "明年常聚"。

## 收尾

12. `me.html`：个人页 + 圈子设置（节律设置/顺延）+ 演示控制入口 + 理念文案。
13. `merchant.html?id=v1`：合作商户详情与订座权益（商业化种子的一句话展示）。

## 次线一句话带过

- `create.html` 建圈：选类型→预填名字→邀请卡片→模拟群友点卡入圈；
- `message.html`：三类提醒分组（该张罗啦/等你表态/想念大家了）。

## 重置

演示结束点「演示」→"重置演示数据"，恢复初始状态。
