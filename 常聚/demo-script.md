# 常聚 · Gatherly 演示剧本（demo-script.md）

演示入口：**双击 `wechat.html`**。一个群聊里两条消息 = 两条用户路线，各约 4-5 分钟。右下角「演示」悬浮钮可模拟圈友表态/推进时间/重置（重置会清空授权态与数据）。

## 路线①：全新用户（约 4 分钟）

**场景话术**："一个从没注册过的新用户，是怎么进入常聚、组成第一场局的。"

1. `wechat.html` → 群聊第一条消息（小李："我上周组了个局，用的常聚"）→ 点**常聚小程序卡片**；
2. 进入 `auth.html`：**手机号授权弹层**（申请获取你的手机号 · 138 **** 8000）→ 点「允许」；
3. `register.html`：**完善资料**（选头像、昵称、手机号回显）→ 「完成注册」；
4. 自动进入 `index.html?new=1`：**空态圈子列表**"还没有圈子" → 点「＋ 建圈子」；
5. `create.html`：选类型 → 填圈名 → 生成邀请卡片 → 分享到微信群 → 3 位群友点卡入圈 → 进入圈子；
6. `circle.html` → 「张罗个局」→ `propose.html`：选方向 → 一键生成智能提案 → 发出提案；
7. `vote.html`：时间矩阵表态 + 随大流 → 「演示」模拟圈友表态 → 推进 48h → `event.html` 自动定案；
8. **点「分享邀请到群」** → 弹出组局邀请卡预览 + 选群 → 话术："邀请已经躺进微信群，接下来是被邀请人的路线。"

## 路线②：被邀请用户（约 4 分钟）

**场景话术**："群里的朋友看到组局邀请卡，点进来的完整旅程。"

1. `wechat.html` → 群聊第二条消息（阿Sun：这周的局我组好了）→ 点**组局邀请卡片**；
2. `auth.html`：手机号授权 → 「允许」；`register.html`：完善资料 → 完成注册；
3. 自动直达 `vote.html?proposal=p1`（**无需找圈、找局**）→ 时间矩阵表态、地点投票；
4. 用「演示」推进时间 → `event.html` 局详情（定案/出席名单/未表态提醒）；
5. 收尾点题："被邀请人从卡片进来，授权注册后直接落在局上——这就是'缺人补位'入口的雏形。"

## 汇合后的主线（两个路线共用，约 3 分钟，可选）

散场仪式（合影→抽签→记录卡）→ AA 账本（票券/随机买单转盘/最少转账）→ 现场小游戏（曲水流觞/大转盘）→ 年度回顾。

## 次线一句话带过

- `message.html`：三类提醒分组；`me.html`：节律设置/顺延/演示控制；
- `merchant.html?id=v1`：合作商户与订座权益（商业化种子）。

## 重置

演示结束点「演示」→"重置演示数据"（清空时钟/数据/授权态/注册资料），可重复演示。
