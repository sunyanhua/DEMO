## 一、用户账号与认证

### 1.1 注册与登录

| 功能 | 说明 | 重要性 |
|------|------|--------|
| 手机号注册 | 填写昵称、手机号（自动校验格式）、性别、出生日期，上传头像后完成注册 | ⭐⭐⭐⭐⭐ |
| 注册后信息锁定 | 昵称、手机号、性别、出生日期注册后不可修改，页面上以置灰禁用态展示 | ⭐⭐⭐⭐ |
| 微信手机号授权登录 | 通过微信一键授权获取手机号完成登录，弹窗确认手机号后进入应用 | ⭐⭐⭐⭐⭐ |

### 1.2 脱单档案（交友资料）

| 功能 | 说明 | 重要性 |
|------|------|--------|
| 档案引导填写（4 步向导） | 新用户注册后引导完成：①基本资料→②上传照片→③脱单资料→④更多信息，最后一步可跳过 | ⭐⭐⭐⭐⭐ |
| 基本资料填写 | 真实姓名、单位名称（均为隐私字段，不对外展示），需勾选同意《隐私协议》 | ⭐⭐⭐⭐⭐ |
| 照片上传管理 | 上传个人照片（最多 9 张），支持逐张删除，3 列网格预览 | ⭐⭐⭐⭐⭐ |
| 脱单资料填写 | 婚姻状况、身高、体重、属相、血型、学历、职业、地区、民族、户口、家乡（均为必填，下拉选择或输入） | ⭐⭐⭐⭐⭐ |
| 更多信息填写 | 兴趣爱好、才艺特长、自我介绍、择偶标准（均为选填，自由文本） | ⭐⭐⭐⭐ |
| 脱单资料编辑 | 已填档案可随时修改，字段与引导填写一致 | ⭐⭐⭐⭐⭐ |
| 档案隐私设置 | 三种可见范围：全平台公开 / 仅对专区成员展示 / 完全隐藏 | ⭐⭐⭐⭐ |
| 退出脱单 | 在个人中心可主动退出脱单模式，二次确认后生效 | ⭐⭐⭐ |

### 1.3 身份认证

| 功能 | 说明 | 重要性 |
|------|------|--------|
| 实名认证申请 | 上传身份证正反面照片，提交后 1-3 个工作日审核，通过后显示橙色"已实名"标签 | ⭐⭐⭐⭐⭐ |
| 实名认证状态查看 | 已认证展示脱敏姓名（如"张**"）和认证日期，未认证展示上传入口 | ⭐⭐⭐⭐ |
| 单位认证申请 | 选择单位类型（政府机关/国有企业/民营企业），填写单位全称，上传社保证明截图（限 JPG/PNG，≤5MB） | ⭐⭐⭐⭐ |
| 单位认证状态查看 | 已认证展示单位名称和蓝色认证标签，未认证展示提交入口 | ⭐⭐⭐⭐ |
| 认证说明 | 告知用户两种认证相互独立，认证标签会展示在个人主页 | ⭐⭐⭐ |
| 个人资料编辑（基础） | 仅头像可修改，其他基本字段只读；页面顶部提示"注册后不可修改" | ⭐⭐⭐⭐ |

## 四、牵线玩法（CP 配对投票）

### 4.1 CP 展示与操作

| 功能 | 说明 | 重要性 |
|------|------|--------|
| CP 配对并排展示 | 一男一女两张资料卡片并排展示，中间有心跳动画 logo | ⭐⭐⭐⭐⭐ |
| 单方资料详情 | 每张卡片展示：照片、实名标签、昵称、性别、年龄、星座、婚姻状况、属相、血型、民族、学历、身高、自我介绍、择偶标准 | ⭐⭐⭐⭐⭐ |
| 点击卡片进入主页 | 点击任意一方的卡片，跳转到该用户的个人主页 | ⭐⭐⭐⭐ |
| 帮TA选（锁定配对） | 卡片下方"帮TA选"按钮，点击锁定该方，另一方自动轮换新的候选人，可随时解锁切换 | ⭐⭐⭐⭐ |
| 从主页进入自动锁定 | 从个人主页"帮TA牵线"进入时，自动锁定该用户为配对一方 | ⭐⭐⭐⭐ |

### 4.2 投票与结果

| 功能 | 说明 | 重要性 |
|------|------|--------|
| "我觉得能成"投票 | 点击红心按钮，认为两人能在一起 | ⭐⭐⭐⭐⭐ |
| "我觉得不成"投票 | 点击灰心碎按钮，认为两人不合适 | ⭐⭐⭐⭐⭐ |
| 嗑学分变动 | 投票后根据判断与两人实际互动状态的匹配程度，增加或扣除嗑学分 | ⭐⭐⭐⭐⭐ |
| 投票结果弹窗 | 显示结果表情（❤️/💔）、标题、嗑学分变化（+/−数字）、趣味评语（如"锦上添花""棒打鸳鸯""缘聚缘散一念之间""N%用户和你看法一致"） | ⭐⭐⭐⭐ |
| 查看详情 | 投票结果弹窗中"查看详情"按钮，跳转到该 CP 的缘分详情页 | ⭐⭐⭐⭐ |
| 继续牵线 | 投票结果弹窗中"继续牵线"按钮，加载下一对 CP 推荐 | ⭐⭐⭐⭐ |

### 4.3 规则说明

| 功能 | 说明 | 重要性 |
|------|------|--------|
| 玩法说明弹窗 | 解释投票规则：能成拉近两人 / 不成推远两人 / 嗑学分计算方式 / 锁定后每日限 20 次计分 | ⭐⭐⭐ |
| 页面导航 | 顶部帮助图标、奖杯图标、搜索图标 | ⭐⭐⭐ |
