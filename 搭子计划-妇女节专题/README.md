# 搭子计划 — 妇女节专题

> "搭子计划"妇女节特别活动专题页面。

## 项目概述

"搭子计划"平台的 3.8 妇女节特别策划专题页。以"女性力量·由我定义"为主题，为女性用户提供弹幕留言墙、话题动态发布、吃喝玩乐活动推荐等互动功能，致敬每一位闪光的她。

本页面为 **单页专题活动页**，纯静态 HTML，用于妇女节期间的线上活动推广和用户互动。

## 技术栈

| 项 | 选型 |
|----|------|
| 页面语言 | 纯 HTML/CSS/JavaScript |
| 样式 | 自定义 `style.css` |
| 图标 | Font Awesome 6.4.0（CDN） |
| 字体 | Google Fonts — Noto Sans SC |

## 页面结构（单页多区段）

```
┌──────────────────────────┐
│  顶部横幅（Header Banner） │  ← 主题标题 + 副标题 + 节日标语
├──────────────────────────┤
│  弹幕留言墙               │  ← 滚动弹幕 + 用户留言输入
├──────────────────────────┤
│  话题动态                 │  ← 发布图文动态 + 动态卡片流
├──────────────────────────┤
│  吃喝玩乐推荐             │  ← 横向滑动活动卡片（下午茶/瑜伽/烘焙...）
├──────────────────────────┤
│  往期活动回顾             │  ← 已结束活动的图文回顾
├──────────────────────────┤
│  页脚                     │
└──────────────────────────┘
```

## 核心功能

### 弹幕留言墙
- 从右向左滚动的弹幕效果，每条弹幕持续约 30 秒
- 用户可输入留言（最多 30 字），即时发送到弹幕墙
- 预设祝福语库，模拟用户活跃氛围

### 话题动态
- "发布图文动态"入口按钮，引导用户参与话题
- 展示用户发布的动态卡片（图文 + 头像 + 点赞/评论/分享）
- 预设多条女性主题内容

### 吃喝玩乐推荐
- 横向滑动卡片布局
- 包含活动封面图、标签、标题、描述、地址、预约按钮
- 推荐类型：下午茶、瑜伽体验、蜡烛手作、水疗、烘焙课、私教健身等

## 设计风格

- **配色**：粉色系为主（花瓣粉 `#f8e8e0`、玫瑰粉 `#e8c4b8`），营造温馨女性氛围
- **装饰元素**：樱花 🌸 点缀，花朵背景图
- **字体**：Noto Sans SC，轻盈优雅
- **布局**：全屏纵向滚动，各区块交替背景色

## 开发约定

- 弹幕系统为纯前端实现，支持键盘发送（Enter 键）
- 动态发布为模拟功能（展示 UI 流程，不实际提交数据）
- 活动卡片为静态数据，点击预约按钮弹出提示
