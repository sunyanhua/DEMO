## 各项目详情

### 1. 1039发现

活动/票务/商品一站式服务小程序（H5 DEMO 版）。面向北京交通广播听众，提供活动报名、票务购买、文创商品购买三大核心功能。

- **技术栈**：纯 HTML/CSS/JavaScript，Tailwind CSS（本地），Lucide Icons（本地）
- **页面数**：10+ 页（首页、活动列表/详情、票务列表/详情、商品列表/详情、订单确认/成功、我的等）
- **品牌色**：金 `#f2a600` / 紫 `#836ec2` / 蓝 `#9adff3` / 粉 `#fdbeda`
- **文档**：[README](./1039发现/README.md) | [CLAUDE.md](./1039发现/CLAUDE.md)

### 2. 搭子计划

面向都市年轻人的交友社区平台，支持线下活动发布、线上快速轻社交。用户可浏览和发布活动、发布动态、私信搭讪、个人主页展示等。

- **技术栈**：React 19 + TypeScript + Vite + Lucide React
- **组件架构**：Layout（底部导航等）/ Home / Shared 组件集合
- **用户角色**：普通用户 / 实名认证用户 / 合作认证用户（商户/主理人） / 平台管理员
- **文档**：[README](./搭子计划/README.md)（功能需求说明书）

### 3. 搭子计划-妇女节专题

"搭子计划"的妇女节特别专题页面，包含弹幕留言墙、话题动态发布、吃喝玩乐活动推荐等功能。

- **技术栈**：HTML + CSS + JavaScript（Font Awesome 图标）
- **页面数**：1 页（全屏滚动式专题页）
- **主题**：女性力量·由我定义

### 4. 军超联赛

第二届"新长征杯"全民国防教育军事体育超级联赛官方展示页面。2026 年 9 月举办，纪念长征胜利 90 周年。

- **技术栈**：HTML + CSS + JavaScript（Font Awesome + Animate.css + Google Fonts）
- **页面数**：1 页（多区段滚动：赛事介绍、组织单位、时间地点、比赛项目、报名参赛、奖项设置、联系我们）
- **主题**：重走长征路，再塑长征魂

### 5. 拾光聚会

北京交通广播车友活动社区平台。集广播收听、商户展示、活动详情、社区交流于一体。

- **技术栈**：HTML/CSS/JS + Tailwind CSS（CDN）+ Lucide Icons（CDN）
- **页面数**：10+ 页（首页、广播、发现、社区、商户列表/详情、活动详情、报名表单、我的）
- **品牌色**：橙 `#e8a87c` 为主色调，辅以多色 vibrant 体系
- **底部导航**：首页 / 广播 / 发现 / 社区 / 我的

### 6. 他俩能成

相亲交友 H5 小程序 DEMO。核心定位是"自己做媒"——用户既可以为自己找对象，也可以为别人牵线配对。

- **技术栈**：纯 HTML/CSS/JavaScript，Tailwind CSS（本地），Lucide Icons（本地）
- **页面数**：38 页（首页、活动、缘分速配、牵线玩法、广播、专区、排行榜、个人主页、聊天、各类个人中心子页面等）
- **品牌色**：粉 `#e04d2c` / 橙 `#F06840` 暖色系
- **三种角色**：脱单用户 / 嗑学家（牵线撮合方） / 亲友团
- **文档**：[README](./他俩能成/README.md)（前端开发手册） | [CLAUDE.md](./他俩能成/CLAUDE.md)

## 开发约定

- 各子项目独立运行，无跨项目依赖
- 纯静态项目优先使用本地资源副本（`lib/` 目录），避免 CDN 依赖
- 图片资源统一放在各自项目的 `images/` 目录下
- 页面间跳转使用相对路径 `<a href>` 链接
- 每页独立可预览，不需构建（搭子计划 React 项目除外）
